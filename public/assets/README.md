# Optional Tiny Town tileset

On the first Windows start, \`scripts/install-art.ps1\` downloads Kenney's **Tiny Town** 16×16 pixel art (v1.1) to \`kenney-tiny-town.png\`.

- Creator: [Kenney](https://kenney.nl/assets/tiny-town).
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
- Source: Official Kenney Tiny Town download, with a read-only GitHub mirror fallback.
- Atlas size: 192×176 pixels (12 columns × 11 rows, 16×16 px each).
- No third-party art is included in this repository: its files are installed locally.
- The self-contained procedural village art always remains available.
- Use the village's **Art** button to compare the art treatments without restarting.

If network access is unavailable, run \`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-art.ps1\` after reconnecting, or place a legally obtained Tiny Town \`tilemap_packed.png\` under this directory as \`kenney-tiny-town.png\`.
